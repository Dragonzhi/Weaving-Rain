# 风织雨 / Weaving Rain

Godot **4.7.2 stable** 最小可玩验证。三维地形、二维天气场和程序化体积云，采用简洁分层色块风格。

用已安装的 `D:\SteamLibrary\steamapps\common\Godot Engine` 中的 Godot 打开本目录的 `project.godot`，按 **F5** 运行。主场景是 `scenes/main.tscn`，不需要 .NET 或第三方插件。

## 怎么玩

1. 从左侧青色水汽开始，按住鼠标左键，把湿空气推向山坡。只有朝上坡的有效气流能抬升成云。
2. 划过云边，调整位置并向目标附近收拢。快划更强，慢划适合修正；松手后风逐渐衰减。
3. 局部厚云维持约 2 秒开始下雨。观察云上提示、雨线和地块水量；目标外的雨不会计入地块。
4. 水量进入 100–150 后移开危险雨云，或切断补给后等待储水耗尽。虚线框是安全缓冲区；其中的雨、厚云或成雨进度会阻止完成。超过 150 需重试。

| 操作 | 作用 |
| --- | --- |
| 左键拖动 | 局部拨风，上下层同时受影响 |
| R / 重新开始 | 恢复同一湿空气初始局面 |
| 空格 | 暂停 / 继续 |
| F2 / 云交互小样 | 预置云，只验证变形、拾取与风，不结算目标 |
| F3 | 帧时间、模拟时间、水分误差与测试参数 |

点击但不拖动不会造风；失去窗口焦点会结束当前拖动。成雨后的雨云响应较弱，需要提早收尾，切断补给不会立即停雨。

## 实现与调参

- `scripts/weather_simulation.gd`：48×40 网格、守恒搬运、山坡抬升、随云搬运的成雨进度、降雨和安全结算。rain 是 cloud 总水量的子集，不能重复相加。
- `scripts/weather_view.gd` 与 `shaders/`：程序化场景、实时云水纹理、最多 32 步体积云、云影、水汽和雨线。纹理是运行数据，不是固定云素材。
- `scripts/wind_input.gd`：相机射线定位与固定参考平面；`scripts/game_hud.gd`：操作反馈和结算。
- 在主场景根节点的 **Weather Settings** 资源中调整风刷、风衰减、成雨与雨量参数。默认值也在 `scripts/weather_settings.gd`。这些值是测试起点，不是最终平衡。

原型固定初始水汽，无随机风和额外海面补给；少量雨云残余水分会回到低空。边界采用封闭水分边界，减少验证时水分凭空消失；不代表正式游戏世界规则。河流为装饰，不参与供水。

## 验证

用下面的 PowerShell 命令运行全部检查。脚本等待每个 Godot 进程结束并检查日志，不把 GUI 程序刚启动时的返回值当作测试结果；日志保存在 `.godot`。视口检查使用实际 D3D12 渲染，其余使用 headless。

```powershell
.\tests\run_checks.ps1
```

- 30 项规则检查覆盖局部快慢拨风、上限与惯性、迎坡 / 平地 / 顺坡抬升、水分收支、成雨维持与回退、雨水同云搬运、补给和断供、空间雨量、完成与失败、云密度拾取及局部变形；不可见的微量成雨进度不会阻止安全完成。
- 9 项视口检查通过真实输入分发验证云身命中、固定拖动平面、界面防误触、在按钮上松手、失焦、暂停与重试。
- 完整回放从默认湿空气开始，每半秒至多一笔局部拨风，约 32 秒、64 笔完成，地块最终约 120.08。回放读取天气状态选择位置与方向，不向正常玩法加入自动操作或注入云水。
- 实机在本机 NVIDIA RTX 4060 Laptop GPU / D3D12 Forward+ 检查。帧时间是短时采样，仍需长时手动游玩测试。

正式初始局面和降雨实机图见 `docs/previews/`。尚待玩家验证：云边命中是否自然、收拢与移云是否好控制、补给路线是否清楚，以及风格细节与概念图的差距。通过自动检查不代表这些体验已被证明。
