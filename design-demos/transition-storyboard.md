# B方向的转场节奏小样

2026-10-16，沿用已确认的 B「风过群岛」做动效迭代；不重新选择界面布局。此处记录可点击 HTML 运动比较及选择；随后用户授权的原生接入见[实施说明](../docs/theme-transition-implementation.md)。用户已认可“风掠切页、云聚换关、轻淡入处理设置和暂停”的组合；水纹不采用。以下保留比较分镜，时长作为原生接入初值，原生效果的实际验收另记，不把此处HTML检查当作Godot验证。

完整转场仅建议用于正式进入／离开关卡、下一关；主界面与选关可用风掠。设置、说明、暂停用0.15–0.20秒轻切换，翻说明页和切选关卡不做全屏遮挡。后续原生接入应在提交切换时取消手势并阻止重复提交，遮挡后加载／切场景，目标就绪才揭幕；玩法计时在可操作后开始，保留加载失败回退。减少动态模式改为短淡入，不追加新的转场音效，先复用已有轻风音色讨论。

HTML用实机截图、Canvas和requestAnimationFrame验证运动，无新依赖；可拖时间轴或慢速播放。三种动效是同一B方向内的比较，不表示三种新界面或真实天气效果。

本轮离线 Edge 检查1600×1000、1280×800、700×900通过：三种动效播放／结束、反向、慢放、设置轻切换、减少动态和时间轴停帧，无页面异常或横向溢出。截图与日志保留 `.godot/transition-review/`；没有执行Godot玩法检查，因为运行代码未改。
