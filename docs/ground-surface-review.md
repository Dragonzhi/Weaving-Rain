## 当时实现的表现（已撤回）

- **近色草地色块**：世界坐标下的低频平滑色块，给原草地增加少量明暗层次，位置固定，不闪动或随镜头滑动。
- **稀疏短草纹**：绿色暗纹、短小双叶形状，程序化绘制在现有地面材质中。没有逐根草节点，没有白色草线；目标周围留白，陡坡逐渐减少草纹与色块。
- **实际降雨湿痕**：草地在接雨时逐渐变深，最大压暗默认10%；不使用高光、倒影或积水效果。停雨后从全湿到全干默认30模拟秒，较轻湿痕更快退去。暂停／结算冻结，重试与切图清空。

田土仍按累计灌溉进度转深并保持湿土，沿用上一轮规则；草地干燥不会改变田土颜色。田池、池水、沙滩、石块和海面材质不启用草地效果。目标内部及略外侧不记录草地湿痕，接雨、安全、容量、评级与实际水分账本不改。

## 当时的实现与参数（已移除）

复用`shaders/terrain.gdshader`，只在实际岛屿顶面启用`grass_surface`。使用同一64×56的双通道显示纹理，R为草地湿润量、G为建图时缓存的植被留白；线性插值连接格子，未添加几何或改变法线。静态草纹由世界位置计算，不使用天气随机数。

`main.gd`在每个真实固定步的`sim.step()`之后调用视图的`record_ground_rain(dt)`，只读取该步`ground_rain`。追赶多步时逐步记录，不用最后一帧雨量代替整段时间，也不按鼠标或画面帧数积累。湿润上升按实际雨量积分、封顶1；停雨按配置时长线性退去。纹理有变化时每秒最多上传15次，每次追赶合并为一次显示上传。

参数位于`configs/scene_style.tres`的“草地层次（仅显示）”，详细注释在`scene_style.gd`：

| 参数 | 默认 | 调整效果 |
| --- | --- | --- |
| `grass_patch_strength` | 0.10 | 大块草地明暗差；0关闭 |
| `grass_mark_strength` | 0.14 | 短草纹深浅；0关闭 |
| `grass_mark_density` | 0.18 | 候选草纹出现比例；过高容易显得杂乱 |
| `ground_wet_darkening` | 0.10 | 草地全湿时的最大压暗比例；0隐藏湿痕 |
| `ground_wet_gain` | 2.0 | 每单位实际落雨增加的显示湿润量，越高越快变深 |
| `ground_dry_seconds` | 30.0 | 从全湿退到干燥的模拟秒数，越高留痕越久 |

保存后R／切图生效，F6不改变显示配置；无效字段沿用既有事务校验，保留上一份有效样式。数值为本轮显示初值，实际强弱由试玩确认。
