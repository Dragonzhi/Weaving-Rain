# 性能与稳定性收尾记录

日期：2026-10-16。基线：`7a28040`。本轮由用户确认空闲采样；固定 Godot 4.7.2 stable Steam、Forward+／D3D12、RTX 4060 Laptop GPU。开发期直接运行项目，没有导出新包。

## 范围与门槛

meadow、valleys、storm_coast 各云／雨／冷空气的静置与持续拖动，共18项。每项预热5秒、采样60秒，真实GPU输出1920×1080。拖动项保留两个风带、天气提示、最多32个箭头及48条白风线。另测用户第九关的雨场静置／拖动。

P95≤16.7ms、P99≤20ms；模拟至少推进采样时长的99%，末尾积累≤100ms。压力字段每5秒由开发脚本补足，排除补足帧；天气会自然转化，这些样本不是正常通关证据。采样期间不并行运行其他项目测试。电脑的系统调度、温度和其他硬件状态没有锁定，因此结果仅适用于本机本轮条件。

## 改动

- 热带准备、抬升与高低空风组合：循环外读取明确类型、packed数组及固定参数，保留原计算顺序与float32实际补水记账。
- 显示与界面：缓存同一地图的田池几何、风带轮廓和风纹／云储备固定曲线；相机、视口、地图、风刷半径变化时按原几何条件失效。预览仍动态计算。
- 平滑与风线：仅整份成雨进度的字节均为正零时跳过相同零平滑；其他状态沿用原路径。相邻索引与第一段已归一化的风向不重复计算。
- 雨线：无光照材质的箱体从24个重复顶点合并到8个角点，原12个三角形的坐标、顺序、正反面与32步遮挡均保留。实际GPU图像逐字节一致，且检查画面中确实存在可见雨线。
- 雨区提示：读取真实落地雨量和遍历连通区域时使用本地数组引用，保留邻居顺序、15Hz发布节奏、覆盖和悬停规则。

未改地图、时限、天气参数、输入规则、积累处理和评级；没有减慢固定步、丢弃积累或减少显示数量来换取门槛。

## 相关验证

模拟原版／当前版四图1716次字段和记账精确对照通过，含风带／漩涡、边缘衰减参数变化和非整步dt。最终雨区优化后另作两图120帧、2640次几何／纹理／雨线buffer及雨区字段精确对照通过。

共享雨网格版本完成34个相关检查／回放条目，均通过；不是整个84项检查集合。覆盖水分、开放边界、风与漩涡、热带、雨区／雨层、显示字段、田池高度、界面和结果。包含正常鼠标教学9.3667秒→level01满风纹真实倒数35.5秒→level02，以及正常需水地块鼠标路线36.45秒。三类历史问题路线各重复3次，未重现原生异常；无漩涡视口路线仍有耗时和雨量变化。

最后雨区循环改动后补验22项真实GPU雨区检查及上述2640次对照，未将此前34条记为最后一次单次全套运行。新增断言保留在既有render_fields、ground_volume和compact_feedback检查中。

最终同源码18项中13项通过，5项拖动P95超标；第九关附加两项均超标，拖动P99也超标。全部20项推进与末积累达标，采样期间没有超过33ms的帧；第九关静置曾短暂积累111.845ms，末尾恢复至7.940ms，不能写成全过程无积累。

## 剩余CPU开销诊断

正式采样结束后，单独用缓存中的插桩副本测meadow冷空气两项各15秒。它不是验收复测，也不替代失败的60秒样本。拖动1129帧中窗口焦点记录均为真；此前正式样本没有逐帧记录焦点，不把此结果套用到所有历史样本。

慢帧的雨区更新平均0.9654ms，对照正常单步帧0.2081ms；箭头刷新0.3843ms，对照0.0703ms。风线平均2.321ms，是显示更新的主要常驻成本。下一步优先细分雨区渐变／纹理提交、箭头候选刷新及风线生成；这些计时只能指导定位，尚未证明某一处改动足以让全部样本达标。

## 稳定性边界与续接

V6尚未解决。两份历史signal 8／0xc000008f日志的GDScript栈进入_dissipate_edges，但没有带符号的原生调用栈，不能据此证明具体原因。另有历史particles空引用，项目中没有对应粒子节点API调用。重复通过只能说明本轮未复现；未升级引擎、改规则阈值或忽略异常。
