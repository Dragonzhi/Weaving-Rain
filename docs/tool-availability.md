# 按关卡开放风工具

2026-10-15。本轮只组织现有工具的开放顺序，保留九关布局、天气、时限、目标需求和评级规则。普通地面仍为纯色，已撤回的草纹和湿痕不重新接入。

## 当前关序

| 地图 | 可用工具 | 学习重点 |
| --- | --- | --- |
| 教学、level01–04 | 拨风 | 迎坡造云、输雨、两处目标分配与农田控量 |
| level05–06 | 拨风、风带 | 持续送汽，腾手处理另一处天气；留意过量风险 |
| level07–09 | 拨风、风带、漩涡 | 收拢湿空气后撤源，再造云和分送；后期利用风暴 |

这是地图可用工具配置，不是次数／能量预算，也不是必须用某工具获风纹。风源共享数量、寿命与三档力度沿用天气配置。正式选关仍无锁关，直接选后面的图也会开放该图配置的工具。

## 在 Godot 中调整

1. 在文件面板打开`configs/maps/levelXX.tres`，或从地图插件进入“打开地图属性”。教学独立编辑`configs/tutorial.tres`。
2. 找到 **Available Wind Tools**（`available_wind_tools`），勾选本关开放的拨风、风带、漩涡。必须保留拨风；不支持全部关闭。
3. 保存，游戏里按R重试或重新选图。F6只读天气手感，不改本关工具；修改编排顺序不会自动改每张图的工具。

文本配置使用Godot原生位标记：拨风1、风带2、漩涡4；合并时相加。只有拨风为1，拨风＋风带为3，三种全开为7；拨风＋漩涡为5也有效。旧地图没有该字段时默认7，不会静默限制旧测试图。新建资源也默认全开，设计新关时再按需勾选。

地图校验会拒绝缺少拨风或包含未知标记的配置，显示具体字段；原有加载回退保留上一份有效地图。工具值作为地图布局快照的一部分交给输入，不在当前局中原地变更。

## 操作和说明

- 底栏只显示本关可用工具，隐藏项不占位置；天气提示按钮保留。底栏按内容缩短，释放出来的画面可拨风。
- 输入的`select_tool()`也检查权限，不能通过隐藏按钮事件选入受限工具。切关取消旧手势并回到拨风；重试保留仍可用的工具，若保存后的新配置已关闭它则回到拨风。风源仍按原规则在重试／切关清空。
- 首次进入开放风带／漩涡的正式地图时，显示原生说明卡；阅读期间整个天气与计时暂停，点击“开始”才继续。直接进入同时开放两种新工具的图时合并说明；本次运行内重试／重访不重复，不增加存档字段。
- 菜单“本关说明”可重看；关闭恢复原先的游玩或暂停状态。说明打开与导航时取消手势，恢复后需要重新按下。普通工具操作提示仍保留；新版引导与配置见[教学和前期节奏](onboarding-and-early-pacing.md)。
- 旧开发图默认全开，不显示正式关卡的首次开放说明；测试直接调用模拟施风接口仍可工作，不将教学权限混入天气搬运规则。
