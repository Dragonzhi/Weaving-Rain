## 素材与循环

原曲由Écrivain创作，来自[作者页面](https://opengameart.org/content/meadow-thoughts)，页面标注CC0。正式素材为`assets/audio/meadow_thoughts.ogg`，不属于本项目原创。完整原曲约149.744秒，最后1.5秒与开头交叉渐变，循环旋转至连续原始采样处衔接，得到148.244秒循环；保留其余乐句，不重新编曲。音乐按约−26 LUFS作恒定增益整理，不使用动态压缩。具体散列与技术检查见[接入记录](bgm-review.json)。

使用Godot原生AudioStreamOggVorbis和AudioStreamPlayer，单独WRMusic总线送入现有Master。播放器属于整个运行会话，重试、切页、切图、结果均不重建或重新从头播放；原3层天气与2个短音声部保留。普通启动渐入，失焦静音并暂停音乐进度，回到窗口续播。暂停保留轻音乐，天气仍按原规则退声。

## 音量和配置

设置页保留声音总开关及总音量，新增独立音乐音量，0可只关闭音乐。偏好仍在`user://audio.cfg`，增加`audio/music_volume`，缺省0.70；旧文件的`enabled`和`volume`含义不变。无效新字段连同本次读取一起拒绝，保留现用值。滑杆即时改变声音，沿用0.25秒合并保存；`--fresh-guide`不读写真实偏好。

`configs/audio.tres`新增参数：

| 参数 | 初值 | 作用 |
| --- | --- | --- |
| music_gain | 2.0 | 基础线性倍率，范围0–4；补偿素材余量，再乘音乐音量及总音量 |
| music_play_ratio | 0.70 | 游玩相对菜单的比例 |
| music_pause_ratio | 0.55 | 暂停／结果相对菜单的比例 |
| music_rain_ratio | 0.80 | 最强可听雨声时，保留的音乐比例 |
| music_fade_seconds | 1.0秒 | 起音及场景混音变化的时间常数，约3秒到95% |

强雨退让读取现有平滑后的真实落雨声强度，不修改降雨、地图或评级。上述参数保存后R／切图读取；F6仍只处理天气。坏配置保留上一有效快照。设置页保留曲名、作者与CC0致谢，并修正勾选文字在浅底上变白的问题。

用户实机反馈默认BGM太轻，即使音乐滑杆100%仍不清楚。首版素材约−26 LUFS，再乘0.65基础增益、0.70游玩比例、音乐音量和总音量，强雨时还乘0.65，累计衰减过多。本轮保留素材、音量偏好及原风雨不变，将music_gain改为2.0（约+9.76dB），校验范围仅此字段扩至0–4；music_rain_ratio改为0.80，强雨额外少压约1.8dB。R／切图读取，已有用户音量不强制改写。
