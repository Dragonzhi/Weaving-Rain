# 教学与正式关卡流程安排

2026-10-14。用户确认顺序为：**现有教学关 → 单田 → 双目标 → 风暴＋蓄水区**，并计划自行追加地图，使难度递进更平缓。

本文件记录已确认的编排方向和后续接入工作。最初仅整理文档；用户随后提供level01并要求简化教学，当前教学已改为独立单水库，完整正式关序仍未接入，游戏的连续测试局仍用旧列表。地图制作入口见[新建关卡与编辑器指南](level-editor-guide.md)。

## 四段体验

| 顺序 | 内容 | 想让玩家掌握什么 | 当前素材／边界 |
| --- | --- | --- | --- |
| 入口 | 水库分步教学 | 发现水汽可交互，迎坡成云、降雨和蓄满；不要求移云与安全收尾 | 独立configs/tutorial.tres，沿实际天气推进三步，容量另配 |
| 单田段 | 独立完成一次灌溉 | 在自由操作下安排造雨、雨量和收尾；可以重试优化 | 用户提供level01并已自行试玩，配置与技术路线另行核对，不直接改其布局 |
| 双目标段 | 分配云雨 | 轮流送雨、风带分工，再逐步引入不同需水量 | 可从旧双目标／需求小样复制，不直接视为正式关难度已合适 |
| 主题段 | 风暴＋蓄水区 | 利用持续供给的强雨，区分池的容错与农田的过量风险 | 复用已实现系统，地图可从storm_coast复制调整 |

每段可以有多张地图，不限定正式总关数。用户新增图先独立保存／试玩，再按体验插入；暂不把测试地图的旧标题、旧顺序直接转成正式关号。

## 接下来需要做的运行时整理

1. 收集正式地图ID与顺序，把可自由选择的开发地图与连续挑战编排区分；新文件自动发现不等于自动成为下一关。
2. 接好教学完成后的单田入口，保留原跳过／重看能力，明确开始、选关与教学入口。
3. 复用现有结算和风纹UI，统一下一关、最终关结束及返回入口的文字和行为，避免旧“返回三处田园”硬编码。
4. 核对已有玩家偏好、最高纪录、重试、暂停、返回教学及自定义地图试玩，不为编排无故清空存档。
5. 用实际关卡完整试玩调整距离、水量与时限，特别回应此前“浇两块田偏难”的反馈；既有技术三星回放不代替新关的难度判断。

正式地图和顺序确定后再实施以上接入；level01目前可独立选择，未加入旧LEVELS，没有增加强制工具、评价条件或新天气。水库教学改变的是入门目标，不放宽普通农田规则。

## 先行制作与验证

关卡可以先用现有编辑器独立制作，不依赖开始界面的新设计。建议另存新文件，保留现有回放基线；不用每张图单独导出游戏。

每关至少检查：正常开局、实际迎坡／冷风或暖海条件、各目标接雨、永久损坏后继续、计时结束、满目标倒数、安全状态失去后取消，以及一条可完整完成的路线。

正式接入会改变入口／结果／流转，届时运行相关视口与完整回归。仅写指南不算代码实现或实机验收。V1正式性能与V6历史异常继续保留；发布、平台上传和新包导出仍按原授权边界处理。
