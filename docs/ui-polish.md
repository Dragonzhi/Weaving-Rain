# 局内信息与表现减法修整

2026-10-16。按用户本轮十二项反馈实施，复用B「风过群岛」的配色、原生按钮与薄云转场。

| 反馈 | 当前实现 |
| --- | --- |
| 天气提示默认关 | 新会话默认关闭流向／抬升箭头和地面雨区；本次运行主动打开后，R／切图继续保留选择。无新增偏好字段。 |
| 拨风黑点箭头 | 仅天气提示打开且正在拨风时显示；实际白色风线始终保留。风刷圆环和拨云时的地面对应提示不变。 |
| 田地／水库虚线 | 鼠标悬浮地块或其小水量UI时显示，离开消失。农田显示原安全范围，水库只显示实际受雨边界，不增加安全条件。短暂成果强调保留。 |
| 启动动画 | 正常启动从薄云覆盖直接揭开主界面，不先合拢、不新增等待页；首次可绘制帧即受遮挡，揭幕后解除拦截。开发直达参数跳过。 |
| 时间图标 | 小钟轮廓、余时弧线和精确的分秒数字；仍读取模拟时间，暂停／结算规则不变。 |
| 局内选关下拉 | 删除控件、专用信号及无用刷新逻辑；选关仍从菜单进入原生九宫格，开发地图入口保留。 |
| 储备云朵条 | 云形轮廓内从左到右填充浅青水汽和灰蓝云水，旁边保留百分比；悬浮说明仍区分当前水量与未来暖海补给。 |
| 风纹章背景 | 三枚局内风纹共用浅色圆角底，不增加输入阻挡。 |
| 左上角标题 | 删除局内“风织雨”，主界面标题保留。 |
| 海面线条 | shader加入不等长、不同弧度、双纹和断续细线，错开位置、相位、强弱和轻微漂动；仍是装饰水纹，不表达实际风。随原显示时钟暂停。 |
| ABC与地块UI | 地块及常驻水量条不显示字母；悬浮详情和结算仍显示字母便于对应。局内雨滴／水位／状态缩至原0.82倍，结果页保留完整大小。 |
| 结算按钮 | 复用主界面的同一Theme、字体及悬浮／按下状态；下一关采用同一PrimaryButton，其余采用同一普通按钮。保留所有原生按钮及点击行为。 |

所有新增云形、时钟、背景和悬浮信息均穿透输入。地图、目标需求、受雨／安全判定、天气推进、音频、风源寿命、评级和玩家存档未改。教学标记继续独立说明当前步骤，不随天气提示默认关闭而丢失。天气提示的显示检查与旧回放主动打开提示，不能因此把正式默认值写回开。

实现入口：`scripts/game_hud.gd`、`hud_visuals.gd`、`weather_transition.gd`、`weather_view.gd`与`shaders/ocean.gdshader`。完整技术结果、失败及分段续跑边界见[本轮记录](ui-polish-review.json)。新脚本`tests/test_ui_polish.gd`检查启动拦截、悬浮、穿透、较小UI、真实重试及继续；实机截图留`.godot/ui-polish/`，是显示夹具，不当正常通关证据。V1正式性能及V6历史异常保持开放；不导出新包、不自动提交或推送。

## 本轮检查结果

最终1280×720与1920×1080各27项显示检查通过；1280原菜单59项、转场38项通过。84个配置条目完成分段覆盖，五份旧路线比较通过；中途旧测试字段及一次计时图标缩进错误已修复并留在记录中，不写成一次未中断全套通过。正常湿空气、真实鼠标从主界面教学9.3333秒→首关35.8秒满风纹真实倒数→level02通过，2656个鼠标事件、无输入阻挡和拾取误差；不代表九张用户地图都已完成满风纹路线。

第九关1920×1080静置／拖动两份5秒雨场短样，P95为18.978／19.549ms，P99为22.343／20.618ms；推进4.8833／4.6秒、末积累约240／563ms，均未达到原门槛。默认提示关闭，拖动含两个风带，白风线保留；没有前后版本对照或隔离后台负载，不据此归因本轮显示，也不替代正式长性能V1。新观感仍待用户试玩。

### 图标居中后续

按用户三张截图，将水库／雨滴内容按实际可见宽度居中：缺水时不为不存在的状态符号预留空位，出现安全／警告时整体居中；水库同时补偿碗形轮廓的顶部留白。时钟与时间文字按实际字体宽度整体居中，底框大小不变。两尺寸各27项显示、1080水滴24项检查再次通过，并核对实际GPU画面；仅布局修整，未重跑完整规则或性能。

### 结算返回按钮修复

用户实机指出“返回主界面”点了无效。根因是每次HUD重绘先隐藏再显示该原生Button，导致按住跨帧时状态被取消；改为按结算状态保持可见。回归检查先在修复前用按下／松开间8次重绘复现失败，修复后两尺寸各30项显示检查、结算47项及菜单59项通过。回到主界面保留原内存局面；已结算时仍按原行为显示“开始旅程”，不改变导航规则。本次仅相关复验，不是再次完整天气回归。
