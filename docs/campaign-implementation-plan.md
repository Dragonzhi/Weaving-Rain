# 可配置关卡编排实施计划

2026-10-15，用户授权实施。当前存档基线为main的29229df。

## 范围与数据

新增Godot原生资源`WRCampaign`及`configs/campaign.tres`：`tutorial`引用独立教学地图，`levels`为按游玩顺序排列的地图资源数组。初始只收录用户的level01；以后在属性面板增删、拖动排序即可，不需要连续文件名或修改脚本。地图标题、天气、需求、时限仍留在地图资源，不复制进编排。

使用资源引用而非目录排序，正式列表和开发地图发现分开。加载校验教学为单水库、正式图为计风纹地图、资源有效、标识与文件名一致且不重复。整份配置验证后才替换当前快照；坏配置保留上次有效列表并提示具体字段。首次加载失败只提供重试／教学和开发回退，不静默把测试图当正式关。

## 运行流程

1. 首次启动仍进入教学，完成或跳过进入正式第一关；已有入口偏好直接进入第一关。重看教学后返回此前正在玩的地图。重试不重读关序，避免中途改序影响当前局面。
2. 原生控件选关面板按配置显示关号、地图标题与最高风纹，不锁关；打开时暂停并取消手势，关闭恢复原暂停状态，选择新图才重新开局。菜单和成功／失败结果都可返回选关。最后一关通过显示“本轮挑战完成”，返回选关而不绕回旧测试图。
3. 教学引用、正式关序在启动或打开正式选关时重读；F6只管天气，R仍管当前地图／完整配置。重读不重置当前天气，返回后选关及后续跳关使用新表；当前地图即使被移出列表也能继续玩，完成后返回选关。
4. 旧测试图保留独立开发浏览入口、`--layout`、`--map`和编辑器试玩，不混入正式数组。不修改地图、星级规则、存档格式和以地图ID保存的最高纪录。

## 验证与交付

补配置校验与实际视口流转检查，覆盖首次／跳过／重看、单关终点、多关排序、无通关禁止下一关、失败选关、暂停／取消输入、坏配置回退、重载、当前关被移出列表、编辑器试玩与偏好／最高纪录隔离。使用临时配置覆盖多关，不把测试图加入正式文件。实际按钮跨帧按下松开，检查两种视口尺寸与选关截图。

流程变化运行完整规则、GPU场景及既有回放；如旧幼苗回放或原生异常再现，保留失败、分段续跑其余项目，不改天气阈值掩盖失败，不宣称整套通过。正式长性能V1与异常V6继续开放。本轮不导出新包、不推送远端。同步编辑指南、看板、策划及开发说明，交付可调编排与真实验证记录。
