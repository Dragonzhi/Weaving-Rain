# 地图编辑与调参

使用项目固定的 Godot 4.7.2。编辑插件已启用，打开 `scenes/map_editor.tscn`，在场景树选中 **MapAuthor**。右侧出现“风织雨地图”面板。

保持 MapAuthor 根节点的默认变换；地图的位置和尺寸通过资源属性与手柄修改。

## 制作地图

1. 点击“加载地图”选一个现有 `.tres` 作为起点，或重置为原布局模板。
2. 在 3D 视口拖动手柄：岛中心与两条轴控制位置和尺寸；每座山有位置、宽度和高度手柄；A、B 与湿空气有位置手柄。选中节点后按 F 可聚焦，使用 Godot 自带视口操作调整观察角度。
3. 点击“打开地图属性”，修改岛形预设、轮廓起伏、地图名称和提示；展开山体、湿空气数组修改细节。面板按钮可添加和删除山体、湿空气。Ctrl+Z 撤销，Ctrl+Shift+Z 重做。
4. 使用面板添加／删除地块，首版支持 1–3 处。地图编辑范围为 X `-12–12`、Z `-10–10`。山脚须在岛内，山体高度是高于平地的高度，最大 2.5；目标整个受雨区须在平坦陆地且互不重叠。红色目标或山标签、面板文字及节点警告指出无效区域，修正后才能试玩。
5. “地图另存为”建议保存到 `configs/maps/`，文件名成为地图标识。运行时会列出该目录中标识与文件名一致的地图。“保存地图”更新当前资源；要保留原模板，使用另存为。
6. 点击“试玩当前地图”运行自由局。试玩读取 `.godot/map-playtest.tres` 临时副本，不要求先覆盖正式地图。R 重试同一副本；再次点击试玩使用最新编辑内容。试玩不读取或写入正式最高星数，也不写首次入门偏好。

地图属性的 `plot_regions` 数组按 A、B、C 顺序指定 `WRPlotRegion` 资源。缺省或 null 保持矩形；`shape` 可选 `rectangle`、`circle`、`ellipse`。`half_axes` 是矩形半边长或椭圆半轴，`Vector2(0, 0)` 继承全局 `plot_half`，自定义尺寸的两个分量至少 0.5；圆形使用 X 为半径。显示、接雨归属、安全轮廓和校验共用形状。面积越大，相同实际落雨量换算的地块水量越小；形状不决定作物需求。

## 为地块选择需求

地图属性中的 `plot_needs` 数组也按 A、B、C 顺序填写，可拖入 `configs/plots/ordinary.tres`（普通田 100–150）或 `seedling.tres`（幼苗 40–55）。空项／省略继承 `configs/weather.tres` 的全局需求；旧地图不需要迁移。地图编辑器预览与列表显示类型及需求，增删、撤销／重做和另存会保持关联。

直接打开需求 `.tres`，用 Godot 属性面板或文本修改并保存：

| 字段 | 含义与调整效果 |
| --- | --- |
| `id` / `display_name` | 类型标识与显示名；同一类型可给多块地复用，本局水量仍独立 |
| `target_water` | 达标量，有限正数；调高需更多雨，调低更早够水，也须更早移云 |
| `flood_water` | 过量上限，必须大于达标量；越接近达标量越怕涝，恰等于不损坏，超过立即永久损坏 |
| `appearance` | `ordinary` 或 `seedling`，只影响占位植物的密度、大小与长势，不改变雨量 |

需求配置使用现有按面积归一化的雨量单位，不再乘一次面积。更改需求保存后 **R 重试或重新选地图** 生效；F6 不改变本局需求。失败会保留上一有效配置并报告资源与字段。共享预设应明确保存到其 `.tres`，临时试玩不会自动回写预设。

运行时从布局列表选择 **需水差异小样**，或用 `--fresh-guide --layout=needs_lab` 启动。两块面积相同，A 普通田、B 幼苗；一星可通关、两星需主动安全收尾，不触发三星自动倒数。此图不加入原正式两关顺序。

水量条按需求填满，够水后随着余量减少从蓝变黄；超过上限变红且保持损坏。满条／长满仅表示够水，危险天气与安全确认仍单独判定。正式多雨滴造型留到 UI 美化。

开启 `star_level` 后，地图采用“一地块一星、一星可主动结算、损坏后继续”规则；关闭时仍须全部地块适量并安全，任一过量即需重试。安全形状在每个方向增加 `safe_half - plot_half` 的半轴余量。星级地图的未完成且未损坏地块也需要清除附近危险天气，才允许提前结算。原练习图的规则保持原样。

`time_limit_seconds` 是该地图星级玩法的时限，单位秒，允许 1–3600，当前两关与需水差异小样使用 180 秒测试初值。缩短会压缩输雨与安全收尾的时间，延长会留出更多争星机会；修改、保存后重新开局生效，F6 不改变本局时限。到时自动结算，仅给已适量并连续安全的地块计星，其他地块即使仍有危险天气也不会拖住结算；零星提供重试。入门、旧练习局与 F2／F4 隔离小样忽略时限，暂停冻结计时。地块的安全维持时间仍由全局 `safe_seconds` 决定，不能只在最后一刻清掉天气就立刻得星。

岛形首版使用原岛、长岛、双翼三个预设，不支持自由绘制海岸。多山重叠取最高地形，不把高度相加；交界可能形成山脊。装饰河流可以关闭。`configs/maps/ridges.tres` 是两山两路测试地图，策略价值尚待试玩；不视为已验收关卡。

湿空气源的浓度是全局 `initial_humidity` 的倍数，覆盖 `spread` 表示两个方向的尺寸，`falloff` 越大越集中。只在开局提供水汽，不持续补水。正式开局不产生云或冷空气。

正式星级关卡的天气储备条以开局总水分为 100%，区分低空水汽与云中储水。水分不足提示采用保守上限：即使把全部剩余储备送到最接近适量的未完成地块也补不到，才允许按当前星数提前结束。需求按各块实际面积换算，已够水或损坏的地块不参与缺水比较；水分充足并不保证输雨路线可行。仅提示和开放按钮，仍可继续安全收尾；不会自动结束，也不提供持续补水。

## 调整天气手感

打开 `configs/weather.tres` 修改属性并 **保存资源**。该文件是所有地图共用的天气配置，可以直接编辑文本。Godot 的资源保存与场景保存是不同操作，试玩前确认配置已经落盘。

试玩中按 **F6** 应用拨风和云响应，当前水汽、云水、雨和地块水量保留。加载后屏幕提示已应用项及重试生效项。F6 仅编辑器运行或 `--dev` 开发启动可用。

浮点参数均须为有限非负数；风刷半径、最大风速、力度封顶速度、成雨阈值、维持时间、水量换算倍率、安全时间和受雨半边长须大于零。最高拨动力度须不低于最低力度，过量上限须高于适量下限，安全半边长须不小于受雨半边长。下表另列有上限的参数。

| 参数 | 含义与单位 | 生效时机 |
| --- | --- | --- |
| `brush_radius` | 风刷半径，世界单位；最大 8 | F6 |
| `max_wind` | 鼠标风速度上限，世界单位/秒；最大 12 | F6 |
| `wind_decay` | 风衰减率，1/秒；越大松手后越快停 | F6 |
| `wind_spread` | 邻域传播率，1/秒；允许 0–60 | F6 |
| `stroke_min_power` / `stroke_max_power` | 最慢与最快拨动的施力倍率 | F6 |
| `stroke_speed_full` | 达到最快力度所需的鼠标世界速度，世界单位/秒 | F6 |
| `stroke_gain` | 每段路径的施力倍率 | F6 |
| `hold_gain` | 续吹及风带的加速度增益，0–10 世界单位/秒²；续吹乘拖动轻重倍率，风带乘所选档倍率；调大输送更快也更易过量，0 不再加力 | F6 |
| `source_powers` | x/y/z 分别为弱／中／强，有限、升序的 0–10 倍率，默认 0.35 / 1.425 / 2.5；调大对应档更强，与拖动速度和风带长度无关 | F6 |
| `source_lifetime` | 风带寿命，1–30 秒，默认 30；调大可腾出更久的操作时间，也更容易持续补给过量 | R |
| `source_fade_seconds` | 寿命最后的线性减弱时间，0.1 秒至总寿命，默认 2；调大更早变弱、停止更平缓 | R |
| `source_limit` | 同时保留的风源数量，1–4，默认 2；满额后须先撤除，调大允许多路输送但更难控雨 | R |
| `cloud_drag` | 云水越集中时的阻力系数；越大越难搬动 | F6 |
| `rainy_cloud_response` | 激活降雨后的相对响应，0–1 | F6 |
| `rain_response` | 云运动响应的下限，0–1 | F6 |
| `initial_humidity` | 初始湿空气浓度；各源再乘自身倍率 | R |
| `lift_rate` | 山坡气流抬升效率 | R |
| `cloud_threshold` | 开始累计成雨进度的显示云水阈值 | R |
| `hold_seconds` | 厚云维持时间，秒 | R |
| `progress_retreat` | 散薄时成雨进度回退倍率 | R |
| `rain_rate` / `rain_base_rate` | 储水释放比例率与基础释放量，按秒计算 | R |
| `rain_end_density` | 回收微量残雨到低空的阈值 | R |
| `plot_water_scale` | 落雨质量换算地块水量的倍率 | R |
| `cold_enabled` | 启用降雨冷风能力 | R |
| `cold_from_rain` / `cold_cap` | 实际落雨产生冷空气的倍率与强度上限 | R |
| `cold_decay` | 冷空气自然衰减率，1/秒 | R |
| `cold_outflow` / `cold_max_speed` | 冷空气梯度出流倍率与速度上限 | R |
| `cold_lift_rate` / `cold_lift_cost` | 迎面汇聚抬升效率与冷空气消耗倍率 | R |
| `cold_minimum` | 可产生有效抬升的最低冷空气强度 | R |
| `target_water` / `flood_water` | 适量下限与过量上限 | R |
| `safe_seconds` | 安全收尾维持时间，秒 | R |
| `three_star_finish_seconds` | 正式三地块关卡三星后的自动结算倒数，0.1–30 秒；默认 3，越大留更多观察时间，失星取消并重计 | R |
| `plot_half` / `safe_half` | 受雨与安全区域的半边长，世界单位 | R |
| `edge_decay` | 最外侧两单位缓冲内的消散率，1/秒 | R |
| `open_boundary` | 正式玩法须开启；关闭只用于直接构造旧开发回归 | 开发检查 |

F6 后按 R 会重新加载保存的配置；地图和结算相关缓存随新模拟重新建立。数值或地图无效时保留现用版本并指出字段。增大 `plot_half` 可能使地图不再满足平地或不重叠规则，需要同时调整地图。提高风力或添加大量山体后应重新检查手感与帧时间，默认参数不是最终平衡。

## 开放边界

24×20 地图外有四单位海域缓冲，模拟为 64×56、每格 0.5 世界单位。水汽、云和冷空气可以进入海域，在最外侧两单位逐渐消散并离开，不堆回边缘，也不会从别处补回。吹走水分会减少后续可用储水；没有足够水时可按 R 重试。

开发启动可使用 `--map=res://configs/maps/ridges.tres --fresh-guide --dev`，或 `--settings=res://configs/weather.tres` 指定配置。未来随机生成器可以输出相同地图资源；本阶段未加入随机生成。
