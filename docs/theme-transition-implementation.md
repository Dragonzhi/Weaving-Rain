## 输入与计时

`main.gd` 的 `navigate()` 接收界面导航请求；`weather_transition.gd` 使用原生 Control 绘制和 Tween，位于独立第 100 层 CanvasLayer，无新图片依赖。原有同步关卡函数供内部调用和开发验证，用户按钮与相关快捷键统一经过导航入口。

开始即取消待拨风、冻结天气／风源寿命／安全与结算计时、拒绝重复导航及快捷键。云幕实际绘制全遮挡后才执行加载；再等新布局与 GPU 画面就绪，揭幕完成后才恢复操作与固定步。遮挡加载等待不计入标称动画时长，不积累转场时间供模拟追赶。保留此前暂停状态，主界面仍只保留当前进程的局面。

地图与教学资源先校验，失败保持当前局面，揭开原页面并显示具体错误。轻淡入直接使用Tween控制新页面内容或HUD透明度，不做GPU回读／截图纹理，完成释放目标引用；窗口缩放沿用逻辑视口，动画图形仅为 UI 装饰，不参与云水、光照或天气模拟。声音沿用已有按钮与暂停渐变，不增加转场音效。
