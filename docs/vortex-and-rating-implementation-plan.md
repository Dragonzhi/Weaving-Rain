# 手势漩涡与固定三星评价实施计划

日期：2026-10-12。状态：该版本已实现并留存历史审阅。用户后续改为左右键拖半径、滚轮三档，当前实现与验证见[操作修整记录](vortex-placement-review.json)、策划第35节；以下两圈规格保留为当时方案，不作为现行输入要求。

## 1. 本轮目标与顺序

验证“画两圈聚集天气 → 关闭漩涡 → 拨风或风带输送 → 控雨与安全收尾”，改善用户反馈的水汽运输困难。同时统一一田、两田、三田测试局的固定三星评价。

实施顺序：先将已通过试玩的需水小样、图片清理和讨论记录保存为独立 Git 提交；接通新评价与满星收尾；再实现漩涡手势、风场和表现；最后完成正常开局回放、实机审阅及短时性能诊断。

现有地图以测试局及布局名称表达。菜单、地图标题和结果中的“第一关／第二关”改为“三处田园／两山分雨”等布局名，保留资源标识和现有切换顺序。本轮复用已验证的布局、需求、时限及天气规则；后续挑战地图根据漩涡试玩结果再设计。

## 2. 固定三星评价

模拟分别提供实际保住数量和评价星数。总田数 N 使用开局地图的完整田数，损坏田仍计入 N；保住数量 S 只计适量且连续安全的田。

按优先顺序计算：

| 条件 | 星数 |
| --- | --- |
| S = 0 | 0 |
| S = N | 3 |
| S = 1 且未全保住 | 1 |
| 其余，即 2 ≤ S < N | 2 |

一田全保住是三星，两田保住一块一星／两块三星；三田与原评价相同；四田以上保住两块至 N−1 块均为二星。评价函数按任意 N 验证；本轮实际地图与编辑器继续使用现有一至三田范围，四田及以上先覆盖独立评价检查。

最低一星即可完成。原主动收尾、水分不足结束、到时结算、损坏后继续的安全条件沿用；只替换其读取的评价星数。地块状态仍共用 `plot_status()`，填满水条不直接授星。

任意田数的计星测试局全保住后开始满星倒数，沿用默认 3 秒与 `three_star_finish_seconds`。失去安全状态或损坏取消，重新全保住后重计；暂停冻结，到时规则优先。入门、旧非计星练习与隔离开发场景沿用原模式行为。

结果同时显示“保住 S/N 块田”和固定三颗星，逐田保留最终水量、类型及失败原因。地块旁使用“已保住”状态，避免把单块标记解释成一颗评价星；风主题造型留后续美化。

最高纪录增加评价版本。迁移前保留旧文件备份；可以确认历史田数的内置计星图按旧保住数量折算，其中三田纪录不变、两田全保住升级为三星。未知历史田数的自定义图保留旧条目，不凭当前编辑后的田数推定满星，重新试玩产生新版纪录。新版纪录取最高值，重试不降低；`--fresh-guide` 和临时编辑试玩继续隔离正式存档。历史审阅 JSON 的旧星数保持原记录，新增验证注明新评价版本。

## 3. 画两圈生成漩涡

底部选择栏新增“漩涡”工具。选中工具后按下，沿用真实拾取与固定水平参考面；绘制阶段只显示预览，松手时才创建风场。默认拨风画圈仍按普通拨风处理。

输入保存带时间的世界路径，按距离重采样与时间插值，避免鼠标事件数量影响圈数和力度。拟合近似圆的中心和平均半径，用绕中心的有向角累计识别连续同向两圈。顺／逆时针以玩家在屏幕上看到的旋向为准。

识别初值：目标绕转 720°，允许末端约 10°闭合误差；末端离起点不超过半径的 0.35；径向相对偏差不超过 0.30，同向绕转一致性至少 0.85。半径范围先用 0.75–5 世界单位，正常观察样本以 2–3 单位为主。接受手画轻微不圆，拒绝直线、单圈、折返涂画、明显向内螺旋及两圈中心大幅漂移。拟合失败给出具体短提示，不截断或悄悄缩小范围。

两圈成立后锁定中心、半径、旋向及档位，预览显示“已可释放”；继续多画不累加力度。停住等待松手不会降低已确定的档位。松手须仍在有效场景内，中心与有效路径须在天气模拟区；范围外已有天气可自然流入，范围边缘不形成空气墙。

进入界面、离开视口、失焦、暂停、切换工具或重试取消未生成手势。结算停止输入。已放漩涡位置固定，聚集后通过下方原生按钮关闭，再用现有拨风／风带运输；不增加抓取中心搬云操作。

## 4. 速度选择三档固定收拢力度

使用有效前两圈的世界路径长度除以绘制耗时，包含两圈内部的停顿，忽略起笔前和两圈完成后的等待。速度只选择弱／中／强之一；同一档内不做连续力度插值，额外圈数不增加力度。

以下是可调小样初值：

| 参数 | 初值／单位 | 用途 |
| --- | --- | --- |
| 弱／中速度分界 | 4 世界单位/秒 | 低于分界为弱档 |
| 中／强速度分界 | 8 世界单位/秒 | 从第一分界至第二分界前为中档，达到第二分界为强档 |
| 三档向内加速度 | 0.7 / 1.4 / 2.8 世界单位/秒² | 固定的弱／中／强基础值 |
| 切向旋转加速度 | 1.4 世界单位/秒² | 首轮独立固定，旋向由手势决定 |
| 聚集核心半径 | max(0.5，范围半径 × 0.20) 世界单位 | 中心保留一小片聚集区域 |
| 外缘柔化区 | 最外侧 20% 半径 | 源施力逐渐减弱 |
| 寿命／末段减弱 | 30 / 2 秒 | 复用现有风源寿命与衰减 |
| 并存上限 | 2 个 | 风带与漩涡共用现有风源名额 |

旋转与向内两部分加速度在中心平滑降到零、边缘柔和减弱。中心不吸成数学上的一个点，不直接改水汽位置或删除余量。生成后固定档位，寿命末段仍按统一衰减系数减弱。滚轮继续调风带，不调漩涡档位。

两条速度分界、三档力度、旋转加速度、核心比例、半径范围和识别容错写入现有 `WeatherSettings`／`configs/weather.tres`，注释说明单位、调大／调小的效果及生效时机。校验有限数值、递增分界、三档升序、有效半径和比例；加载失败保留上一有效配置。

F6 即时应用向内／旋转力度、核心与边缘参数及现有风速上限，保留天气、风源档位、位置、半径与剩余寿命，必要时重建缓存。识别参数及速度分界从下一笔手势应用，不在半笔途中改变判定。寿命、名额及天气／结算参数沿用重试生效。三档时间表只是调参参考，实际聚集耗时按范围、天气及当前气流测量。

## 5. 接入模拟与表现

复用现有风源集合、稳定标识、关闭与固定步寿命接口，区分风带和漩涡类型；保留旧风带调用兼容。固定漩涡缓存覆盖格、径向／切向方向和柔边权重，每步按加速度 × dt 加入现有风场，叠加后沿用总风速上限、传播、衰减与搬运。

漩涡和玩家风同样作用于低空与云层；自动冷风仍只作用低空。云继续使用厚云／雨云响应，cloud、rain 子集与成雨进度同步搬运。平地只聚集湿空气，成云仍需原有迎坡或有效冷风抬升；风源不增加水分，不直接激活降雨。关闭停止源施力，已有气流自然衰减，须在正常输送验证中观察残留环流。

白色风线读取实际对应层速度，在风场内表现旋转与收拢；既有残留风、干空气和冷风符号继续显示。复用 48 条总白线与 32 个天气箭头预算，云箭头读取实际云响应；不为每条线新增节点。

小中心标记常驻，淡范围圈只在绘制预览／悬停时显示；中心不支持拖动。预览旁显示两圈进度和三档力度，生成后下方风源列表显示类型、档位、剩余时间和关闭按钮。力度配色沿用强红／中绿／弱蓝，仅表示力度。信息均穿透输入，实际工具栏及按钮才阻挡拨风，保持紧凑布局。

新标记和风线处理地形／云遮挡，并保留必要的地面位置提示。暂停冻结风源、预览动画和粒子；重试清源、保留工具，切图恢复默认工具；结算隐藏操作控件并停止施力。

## 6. 验证与交付

### 评价与生命周期

- 覆盖总田数 1–6 的全部保住数量，验证全保住优先、固定 0–3 星及损坏田仍计入总数。
- 一／二／三田实际场景核对满星倒数、失星取消、暂停、重试、到时与缺水结束；结果的保住数量和评价星数各自正确。
- 验证旧纪录备份、已知田数迁移、未知自定义图保留、新版最高纪录和测试存档隔离。
- 手势覆盖顺／逆时针、近似圈、单圈／弧线、折返、半圈反向、中心漂移、内收螺旋、半径边界及闭合容错。
- 用不同事件密度、视口尺寸及帧率重放同一带时间路径，圈数、中心、半径和档位一致；同档不同速度施力一致，三档有差异。
- 检查原生按钮跨帧关闭、风源到期移位、共同上限、界面松手、失焦、暂停、F6、重试与切图。

### 天气与实际用途

- 检查切向旋向、径向收拢、中心／外缘连续性、叠加封顶、撤源后的残留风及开放边界水分收支。
- 从受控开发字段测量低空水汽与薄云／厚云／雨云的聚集过程，记录进入核心区的质量比例、分布半径、耗时及降雨变化；这些夹具不作为正常通关证据。
- 复用需水差异小样，从正常湿空气开局，以真实鼠标两圈生成漩涡、关闭、再拨风／放风带输送并完成满星倒数。操作回放不注水、不清天气、不改需求阈值。
- 同一初始地图做现有风工具对照，记录聚集／输送笔数、路径长度、耗时、最终水量、损坏与水分误差。若聚集只增加集中降雨风险而未改善输送，先调收拢／旋转参数及操作路线再交付结论，不改全局云阻力掩盖问题。
- 单独检查普通田与幼苗的停止时机，并保留损失后继续的流程。小样通过后再讨论挑战布局，不预先宣称更容易或更好玩。

### 回归、性能与资料

运行完整规则、编辑器、输入、渲染与既有回放，更新新星级断言和满星结束记录。旧三田布局的天气与动作轨迹继续核对；需要增加评价字段的记录按字段比较，不以整个 JSON 字节相同作为新格式要求。

单独做 1920×1080 主循环短时诊断，覆盖两风带、两漩涡及混合风源，检查大量云／雨／冷空气、箭头、白线、P95、P99、长帧、模拟推进速度和剩余积累。继续采用 P95 ≤16.7 ms、P99 ≤20 ms 门槛，不减少模拟推进或放宽门槛；记录短样超标和原生异常。用户暂缓的两张测试图十二项 60 秒空闲性能验收继续作为独立待办。

测试截图和序列默认写入 `.godot/`；审阅后只挑必要当前图进入 `docs/previews/`，旧图及时清理。交付可试玩操作、配置注释、新评价与存档处理、正常开局路线及对照记录、少量实机图，并更新 README、策划、AGENTS 与任务看板。此前需水小样已单独提交 `2cb6873`；本轮新改动保留在工作区供试玩。
