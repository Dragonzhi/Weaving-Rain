# 宣传片准备方案：一场雨的旅程

日期：2026-10-20
状态：35秒成片整体画面已获用户认可；按反馈降低雨声并修整换景声音衔接，技术检查通过，新混音待复听，平台审核待执行。最终剪辑及边界见[制作记录](trailer-production.md)与[技术记录](trailer-review.json)，下文分镜保留为原始方案。

## 定位

建议制作约35秒的独立宣传片：跟随一股湿空气，由玩家拨风带上山坡，变成云雨，再送到需要水的田地／水库。重点是看懂“风改变天气，天气滋养岛屿”的因果关系，以及现有画风的氛围。

旧片visuals/weaving-rain-demo.mp4约25秒，以“借山成云／留风聚云／海上借雨”三个七秒功能段、首尾静态封面组成。新片重新取景与录制，以连续故事、景别变化和声音节奏区分；不沿用旧三段素材再换字幕。平台对内容差异的最终判断仍待上传审核。

## 建议分镜（35秒初值）

| 时间 | 画面与信息 | 声音与剪辑 |
| --- | --- | --- |
| 0–3秒 | 岛屿近景中，白色风线掠过，淡水汽开始流动；直接出现操作结果 | 一次轻拨风声，音乐渐入；不开场静态标题卡 |
| 3–9秒 | 跟随湿空气迎向山坡，抬升后云体逐渐鼓起 | 较长镜头保留变化过程，环境风声渐起 |
| 9–16秒 | 切至较宽景别，风带组织气流，将已有云送向田池 | 用白风线连接镜头，清楚表现玩家干预；不复用旧片风工具功能段 |
| 16–24秒 | 雨落在目标上，切到田土渐深、苗与水面、水库蓄水变化 | 远景雨声渐入，音乐适度退让；保留雨在云下的层次 |
| 24–29秒 | 拉宽看雨停后的岛屿与得到滋润的目标，形成故事落点 | 雨声渐退，旋律回到前景 |
| 29–32秒 | 可选一个新录风暴宽景作扩展：更大的天气也能被引导 | 以轻微节奏提升带出尺度差异；不增加新音效工艺；若破坏平静收尾则删除 |
| 32–35秒 | 回到流动海面／云景，叠加“风织雨 / WEAVING RAIN”标题 | 音乐自然收束，无额外宣传口号 |

## 画面原则

- 使用当前游戏实际渲染与真实天气结果。田地、水库、风带和风暴均取现有版本，不新增游戏机制或提高美术规格。
- 以一条真实因果过程为主线；若补录不同地图的细节，剪辑上清楚换景，不伪装成同一局连续通关。
- 隐去大部分HUD，保留白风线、天气变化及必要的操作线索；避免观众只看到一段自动天气动画。
- 宣传录制可临时调整镜头／裁切，保持正交、配色和既有模型；改动只留在录制工具，不写回玩法相机或地图。
- 录制优先1080p、30fps。确保实际连续画面推进后再定帧率；不用重复帧把低帧率声称为流畅实机。
- 不使用AI宣传插画替代实机天气动画，不用假雨量、注水或阈值修改制造成果。需要时间跳转时明确切镜，不伪装成即时完成。
- 文字以片尾游戏标题为主，无解说。沿用已有CC0配乐及现有风雨声，音乐按分镜剪辑，雨声保持远景与渐入。

## 制作顺序与交付

1. 确认故事方向与约35秒长度；先选一条当前地图可正常完成的造云、送雨、蓄水路线，必要时把田地滋润作为明确换景的细节。
2. 先录低成本镜头草剪，核对前三秒、因果可读性及与旧片区别，再补正式清晰素材；录制脚本与缓存独立，不改变正式地图。
3. 导出1920×1080、16:9、H.264、yuv420p、AAC立体声、MP4，开启faststart。时长至少15秒、文件小于5GB；预计约35秒、数十MB。
4. 核对编码、尺寸、时长、文件大小、完整解码与音频峰值；抽查开头、成云、降雨、结尾及完整播放。用新旧片并排复查构图、片段与叙事差异，最终平台审核另记。
5. 交付宣传片、简短审阅入口及来源／镜头时间表；不覆盖旧实机演示，不重新打包游戏，不自动上传。
