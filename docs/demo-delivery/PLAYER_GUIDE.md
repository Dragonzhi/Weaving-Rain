# 风织雨 / Weaving Rain

制作：**ZLOONG · 智龙** · 开发Demo

拨动风，织起云，把一场雨送到需要它的地方。

## 开始游玩

最终Windows包解压后运行`WeavingRain.exe`，无需安装Godot。第一次建议选择“开始旅程”，从水库教学开始：找到淡色覆盖与流动细丝表示的湿空气，迎着山坡把它推过去，等待成云、降雨，填满水库。

## 鼠标与工具

| 操作 | 效果 |
| --- | --- |
| 拨风：左键拖动 | 沿路径推动空气，快划更强，慢划更柔 |
| 拨风：先拖出方向，再按住停留 | 沿最近方向继续吹；再次移动可调整 |
| 风带：左键拖动、滚轮调档、松手 | 留下一条持续吹风的风带，默认约30秒 |
| 漩涡：左／右键拖出半径、滚轮调档、松手 | 左键顺时针、右键逆时针，收拢范围内的空气 |
| 风源旁的× | 提前关闭对应风带／漩涡；残留气流逐渐衰减 |
| 底栏“天气提示” | 同时开关流向箭头与地面降雨范围，默认关闭 |
| 空格 | 局内暂停／继续 |
| Esc | 打开／关闭菜单，或从子页面返回 |
| R | 重新开始当前关卡 |

工具按关提供：教学和前四关只有拨风，第五关起增加风带，第七关起增加漩涡。风带与漩涡默认共用两个名额；仅点击、不拖动不会造风。漩涡预览变红时，调整半径回到允许范围后再松手。

## 看懂天气

白色风线表示实际气流。松手后，风会逐渐减弱，云和水汽仍可能继续运动。

湿空气迎着山坡抬升才能成云。灰蓝薄层是降雨留下的冷空气，把湿空气迎向它的前沿，发生汇聚时也能造云。普通漩涡主要用来收拢，聚集后可以关闭，再用拨风或风带输送。

云水集中并维持片刻才会开始降雨。切断补给或关闭风源后，雨云仍会释放已有储水，需要提前移云，给余雨留出空间。

开启天气提示后，地面的淡蓝范围表示此刻实际落雨的位置，操作雨云时会加强。白色风线和实际雨线始终保留。

海上自然风暴有自己的供给与环流。可以从外围慢慢引导，关闭人工风源不会直接删除它。

## 田与池的区别

**农田**需要适量的雨。雨滴表示已经收到的水量，悬停可看准确需求。够水后还要移开危险天气，并维持短暂安全才算保住。蓝色逐渐变黄表示过量余量减少，变红表示永久损坏；一处损坏后仍可照顾其他目标。

**蓄水区**蓄满就完成，继续下雨可以溢流，不会因此损坏，也不要求附近停雨。

## 完成与重试

教学只需要填满水库。正式关卡中，全部目标完成得三枚风纹；未全部完成时，完成一处得一枚，完成至少两处得两枚。至少一枚即可通关。

关卡到时自动结算；全部目标完成后也会短暂倒数并结算。农田在倒数期间失去安全状态，会取消倒数。水分不足时可按界面提示提前结束，也可以继续整理天气。

最高风纹和声音设置会保存。本次运行返回主界面可以保留当前局面，关闭程序后不会恢复未完成的天气。

## 声音与反馈

设置中可调整总音量与音乐音量。背景音乐与素材来源见随包[制作与素材鸣谢](CREDITS.md)。

当前为开发Demo，天气密集时可能出现帧率下降。反馈问题时，记录关卡名、操作、发生的情况和设备；截图或短视频也有帮助。
