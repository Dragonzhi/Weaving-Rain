### 本轮素材与重做方法

[审阅页](media.html)可直接打开查看三图与视频，也可用本地HTTP服务器打开。三图和视频均为1920×1080；视频为H.264／AAC，25.021秒、24fps、约4.33MB。播放器已在内置浏览器读取到1080p完整时长且无媒体错误，离线完整解码与音频检查通过。用户尚未确认这轮画面／混音。

三图保留原生HUD，只在海面留白处排标题和署名；中央330–959行与各自底图逐像素一致。所选画面分别为约13.017／13.017／13.017模拟秒，来源是level03／07／08。未排字底图为`visuals/{mountain,tools,storm}-source.png`。主题关保留其设计中的初始对流云，不把它写成无云开局。完整来源、输入、水分误差、散列和视频流信息见[media-review.json](media-review.json)。

录制脚本`capture-gameplay.gd`借用既有真实视口回放，正常点击工具、拖动与滚轮，不注水、不改天气／相机；三个最终样本合计1068事件，失败／阻挡均为0，漩涡和风带均实际创建成功。录制途中用正常按钮收起可选提示、照片前把指针移到海上，视频保留实际操作产生的悬浮信息。三段都仍在游玩中，不是通关证明。

原始JPEG序列、成对HUD／净画面、WAV、逐帧墙钟／模拟时间、FFmpeg拼接表及审阅帧留`.godot/demo-media/`。逐帧读回与JPEG写盘拖慢模拟，不能作为帧率证据；剪辑沿原墙钟时间播放，没有加速或插帧。视频用现有《Meadow Thoughts》连续配乐和各镜头对应的原生风雨声；这是剪辑混音，游戏音频配置与素材未改。

重做顺序：用固定Godot运行`capture-gameplay.gd`，原生参数加`--resolution 1920x1080`，用户参数为`--fresh-guide --skip-menu --audio-review --shot=mountain --map=res://configs/maps/level03.tres`；另外两组改为tools／level07、storm／level08。必须传完整资源路径，脚本校验实际地图标识及推进时长。随后在项目根运行`python docs/demo-delivery/make-gameplay-media.py --photos`，运行Godot的`render-gameplay-cards.gd`排三图，最后运行`python docs/demo-delivery/make-gameplay-media.py`剪辑及检查。工具依赖本机FFmpeg、Pillow与NumPy，不是游戏运行依赖。

首轮选图被提示遮挡后重拍；一次重拍命令误传短地图名而回退standard，已丢弃，不进入成片。最终三组均核对实际标识和模拟推进；其余检查不扩大为完整玩法／性能复验。本轮不生成游戏包、不提交或上传。
