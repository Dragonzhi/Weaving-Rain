# 《风织雨》开发者日志③：持续风和漩涡，为什么改了好几次操作？

如果一片水汽离目标很远，一直用鼠标来回推，会不会有点累？如果还有另一块田需要照顾，能不能先留下一阵风，腾出手去处理别处？

《风织雨》目前有三种风工具，它们适合处理不同的事情。这一篇介绍它们现在的操作，也回顾一下为什么后来改成了这样。

## 拨风，适合直接动手调整

默认工具是拨风。按住左键拖动，沿路径推动附近的空气；快划更强，慢划更柔，力度有上限。

先拖出方向，再停住鼠标但继续按着，就能沿最近方向续吹。需要换方向时，再拖动即可。只点击、不移动，不会造风。

这很适合把山脚的一小片湿空气推上坡，或在雨云接近田地时轻轻修正方向。松手之后，残留的风还会慢慢衰减，天气不会立即定住。

## 风带，适合留下一段输送

风带可以把一段持续吹风的路线留在场景里。

按下确定起点，拖出方向和长度，用滚轮选择弱、中、强三档，松手就释放。宽度与拨风一致，默认持续约30秒，也可以通过底栏的关闭按钮提前撤掉。

拖得更长，表示覆盖更长的路；想吹得更强，用滚轮明确选档。把两件事分开，是后来根据试玩反馈做的调整：早期的持续风更像一个局部风源，对较长路线的输送不够直观。

留下风带之后，你就可以去照顾另一处天气。不过，田地已经够水时，也要记得检查这条风带是否还在送云过来。

## 漩涡，适合先把分散的空气收拢

选择漩涡工具，按下确定中心，拖动确定半径，滚轮选择力度。左键生成顺时针旋转，右键生成逆时针旋转；松开起手的按键后释放。半径超出限制时，预览会变红。

可以先让分散的水汽向中心聚集，再关闭漩涡，用拨风或风带继续输送。它的位置固定，不能直接抓着中心把整片天气搬走。

这个工具曾尝试让玩家连续画两圈来生成。想象上很有趣，实际讨论和试用后，绘制难度与释放效果都有顾虑，最后选择了更容易控制的拖半径方式。

普通漩涡主要改变气流。在普通平地收拢水汽以后，仍需要有效抬升等条件才能成云。

## 白色线条，告诉你风实际往哪里走

三种工具共用白色风线。拨动时的风、留在场景中的风，以及松手后的残风，都通过它表达运动。

因此，关闭风源后如果还有线条在流动，不一定是按钮失效，也可能是已有气流尚未消退。工具标记说明施力的位置和方向，风线则帮助玩家观察实际结果。

## 目前进展

三种工具已经接入：前几关先用拨风，第五关起加入风带，第七关起加入漩涡。

## 还在打磨的地方

持续输送能腾出手，也可能把多余的雨送向农田。范围、力度和撤风时机是否容易掌握，仍需试玩。

## 接下来准备做什么

收集长距离输送和移云收尾的反馈，再比较不同搭配的实际效果。
