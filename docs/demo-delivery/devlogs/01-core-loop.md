# 《风织雨》开发者日志①：怎样让“把雨送过去”成为一个游戏？

大家好，我是《风织雨》的制作者智龙。

这是一款用鼠标安排天气的小游戏。你可以拨动空气，把湿空气送向山坡，等它抬升成云，再把雨送到田地或水库。

接下来几篇想介绍一下目前的Demo：它可以怎样玩，天气之间有什么联系，以及制作时做过哪些调整。这些内容是对已经完成的开发过程的回顾。

## 第一场雨，可以从山脚开始

进入教学后，先找一找地面上淡淡的水汽。它有缓慢流动的细丝，鼠标可以直接拨动它。

把湿空气迎着山坡推过去，山上就会慢慢形成云。云水集中并维持片刻，雨才会落下来。再调整气流，让降雨覆盖水库，就能看见水位逐渐上升。

这一小段过程，是《风织雨》最想让玩家亲手完成的事情。你下达的是局部的风，接下来的云和雨，则由天气之间的关系逐渐形成。

## 停下鼠标，天气还会继续

雨云里存着水。停止送入湿空气以后，已经形成的雨云仍可能继续下雨；松开鼠标，残留的气流也需要一段时间才会减弱。

所以，如果一块田快浇够了，就要提前想一想：这片云接下来往哪里走？余下的雨可以送给另一块目标，还是应该引到海上？

这种时间差，是操作里需要慢慢熟悉的一部分。风停了，不代表雨已经停了。

## 上一场雨，也会影响下一场雨

降雨会留下低空冷空气。它随雨形成，停雨后逐渐减弱，也能被鼠标推动。

当湿空气迎向冷空气的前沿，有效汇聚也能帮助它抬升成云。这样，玩家除了继续借用山坡，还可以尝试把上一场雨留下的条件利用起来。

这也是游戏回应“涌现”主题的一种方式：第一场雨改变了环境，而改变后的环境，又为下一场雨提供了机会。路线可以随着操作变化，不必每次都回到同一座山前。

## 为什么先教玩家填水库？

早期教学还要求控制农田的雨量、移云和安全收尾，第一次接触时需要同时理解的东西太多。后来把目标换成了可以溢流的水库，并让水汽、山和水库靠近一些。

现在可以先专心看懂一件事：自己的动作，是怎样变成一场雨的。等接触农田时，再学习雨量和收尾。

## 目前进展

这条造雨循环、冷风接力和水库教学已经在Demo里，可以实际操作。

## 还在打磨的地方

第一次玩的朋友能否注意到水汽、理解为什么山前容易成云，还需要更多试玩反馈。

## 接下来准备做什么

先观察第一场雨通常卡在哪里，再决定提示和关卡距离怎样调整。
