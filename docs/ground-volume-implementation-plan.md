# 地面立体感第二轮：田台、池岸与山体落地投影

日期：2026-10-14。状态：用户认可计划并明确指定此前游玩概念图为最终风格目标，第二轮已实现并完成本地检查／导出，实际观感待试玩。当前基线为 `fb97505`，分支 `codex/scene-volume`；不自动合并主线。完整验证与性能限制见[实施记录](ground-volume-review.json)。

最终目标参考：[用户指定的整体风格图](visual-language/scene-references/final-style-target.png)。重点是圆润山体、少量大色块、清楚土边／池壁、柔和贴地投影和青绿／米白／灰蓝关系；参考不是运行截图，不复制地图、云形或目标位置，不承诺逐像素复刻。云继续由真实天气数据生成。

## 1. 反馈与目标

用户反馈云的层次确实丰富，但地面和田地变化不大。首轮场景不能据此记为整体观感验收通过。原因是农田侧面仅0.034世界单位，池满后内壁仅露约0.02单位；山原有分层明暗，统一光向的增益有限，尚无山体落地投影。

本轮以正常游戏镜头能看出田台厚度、蓄水区容器关系及山体贴地关系为目标。近景只辅助检查，不用放大截图代替正常镜头验收。保持平滑轮廓、两三档地面明暗和克制细节，沿用当前已获正面反馈的云效果。

复用现有地图、材料、批量绘制与 `configs/scene_style.tres`。不改变关卡布局、时限、目标需求、评价、天气、山体高度场、坡度或水分收支；不加入写实材质、全屏AO、动态全局光照或大批装饰。

## 2. 农田：真正可见的土台与田垄

- 首轮“顶面保持0.255”的限制在本轮改为可调整显示高度。田面先试0.36，陆地仍为0.22，形成约0.14单位可见土台；0.12–0.20厚度作为小样比较范围，不承诺最终值。
- 外轮廓保留真实矩形／圆形／椭圆，向内做窄倒角，形成亮顶、过渡斜面、稍深侧面的连续关系。倒角不扩张实际受雨区，也不把土台当成新山坡。
- 用少量浅几何田垄替换只有0.045明度差的细纹。田垄约0.02–0.04高，裁切在原轮廓内，与现有植株行列对应；不增加碰撞或天气坡度。显示状态色沿用原入口。
- 植物同步放到新田面，明确叶片与茎的相接关系；幼苗依然比普通作物矮小，生长／萎蔫仍读原状态。优先复用现有网格并适度调整比例，不靠堆植株增加信息密度。
- 脚下小影和土台贴地影适度加强，避免纯黑描边。颜色变化、地块强调及安全符号仍能读懂。

## 3. 蓄水区：满水仍像一个容器

- 保留原目标外轮廓和内侧缩进，重做池沿的窄倒角、顶面、外侧与连续内壁，避免用新增一圈线条代替厚度。
- 池沿显示高度先试0.52；水面先试0.27至0.39的现有映射，满水仍露0.13内壁。先通过提高装饰池岸取得差异，不同时更改全部水位参数。
- 空池有可辨池底；半池有清楚水位；满池仍能看到背侧内壁、迎光池沿和水面。若正常镜头仍不够清楚，再调整显示比例，保持水位对真实容量进度单调，不能改变蓄满阈值或溢流规则。
- 内壁暗部和少量水纹继续沿用共用光向／显示时钟，暂停冻结。水面不加镜面眩光，不盖住池水位UI、风线或实际雨区。
- 首版不加独立溢流粒子或出水河道，避免画出尚未存在的水分去向；蓄满和溢流的现有规则保留。

## 4. 山与岛岸：投影建立地面关系

- 山的形状、顶点、高度场和迎坡能力保持当前实现。先加强山脚到平地的材料转折，再加与共同光向一致的山体地面投影。
- 投影优先由同一实际高度场在建图时生成静态遮罩，光向或地图重建时才重算，材质共享读取。影子跟随真实山体，不画固定椭圆冒充山影；多山遮挡也读取同一最高高度场。
- 使用低对比冷灰绿、短柔边，地面有清楚影形但不压成黑块。山影与云影合成须限制累计压暗，保留水汽、冷风、白线和蓝色雨区的可读性。
- 这是固定光向下的简化静态投影，首版不计算植物的完整实时投影或云内光传输。遮罩分辨率和边缘滤波由正常视口比较确定，避免逐帧做高度场光线采样。
- 海岸保持原位置与海平面。现有岛侧面多数沉在海面以下，不通过抬整岛／降海平面来露侧边；加强沙岸顶面与水面的材料分界，调整近岸浅水带宽度和对比，让岛岸贴水。

## 5. 显示高度与交互对齐

装饰高度可变不代表天气高度场可变。实现时复用一个显示表面高度入口，为田台、植株、接触影、目标旁UI及必要位置标记提供一致标高，避免各处新增不一致常数。

- 雨区仍从最近固定步的 `ground_rain` 读取，深度贴合当前可见田面／水面；不能因田台抬高变成扩大受雨范围。
- 云和雨的深度关系保持，空中雨线／风线／抬升标记仍不写地表深度。
- 检查地面拾取与显示高度差：必要时用同一显示表面确定可见点击位置，随后按原水平坐标和原天气层提交操作。不能让新土台产生迎坡抬升，也不能导致看到田台边却拨到旁边水汽。
- 水汽显示继续表示低空真实字段，不因装饰抬高把整层水汽或冷空气移到新高度。局部遮挡有冲突时先修显示／标记，不修改模拟密度。
- 悬浮信息穿透输入，原生按钮和 `blocks_wind()` 的阻挡范围保留。新增美术网格不加入碰撞体。

## 6. 配置与执行顺序

仅将需要比较的田台高度、池沿高度、倒角宽度、地面静态投影强度加入现有显示资源，详细注明显示用途、范围、调大／调小效果。校验相互关系，例如池沿必须高于满水面；失败保留上一有效配置。R／切图重读，F6仍负责天气手感。

| 顺序 | 实施内容 | 阶段检查 |
| --- | --- | --- |
| 1 | 三种农田与空／半／满池的几何小样 | 正常镜头前后对比，先确认轮廓、土侧面和满池内壁明显可辨 |
| 2 | 植物、田垄、局部接触影及显示高度对齐 | 幼苗／普通作物、状态色、UI、风刷及雨区贴合 |
| 3 | 单山／多山静态投影和岛岸分界 | 共用光向、影子接地、与实际落雨明确区分、提示可读 |
| 4 | 混合目标与热带整景、配置和回归 | 云效果无回退，正常操作／暂停／重试／切图一致 |
| 5 | 少量实机对比图、记录及新独立包 | 记录实际差异与限制，保留现有包，不自动合并或投稿 |

先把田与池做出可见差异，再铺全场。首个阶段交付同镜头／同状态的前后图，正常镜头优先、近景附后；开发注入的水量／天气场景须明确标为显示夹具，不能充当真实通关证据。

## 7. 验证与验收

- 1920×1080和1280×720的正常镜头审阅：三形状田台侧面可见；田垄不是闪烁细线；幼苗与普通作物可区分；满池依然有可见内壁。
- 使用相同初值与输入比较前后模拟字段、水量、目标状态和水分误差。所有几何／投影配置只改变显示。
- 检查田台边缘、水面、池岸与山脚的实际视口拾取、风线／雨线遮挡和雨区深度投影，不能出现浮影、雨区爬上云或UI错位。
- 单山、多山、无山、三种地块、蓄水区及风暴地图均覆盖；重叠阴影不能遮掉低空水汽与有效抬升提示。
- 扩展现有场景GPU检查，保留云表面／字段、雨层／雨区、HUD、风工具、资源与编辑器回归。涉及拾取或流程时运行完整检查，分段／复跑按实际记录。
- 至少补一条混合目标真实鼠标路线，核对造云、送雨与安全收尾；技术通关和玩家观感验收分开。
- 相同视口做改动前后短性能对照，记录P95／P99、场景更新、模拟推进和积累；额外成本优先通过静态网格合并、材质复用及建图时遮罩消化。
- 正式长测继续按用户此前安排留到空闲。目标仍为P95≤16.7ms、P99≤20ms、模拟推进≥99%、结束积累≤100ms。现有风暴短测超标及V1／V6不得因美术更新关闭。
- 重新导出后运行独立包地图启动检查，少量精选截图进文档，批量试验图留在 `.godot/`。

本轮完成标准是地面在实际游玩镜头下有明确体积差异，同时天气与操作仍易读。生成参考图继续作为方向参考，最终观感由实机试玩确认。

## 8. 实施结果与审阅

默认田面0.36、倒角0.055、池沿0.52，水面0.27–0.39保留。修正首轮土侧面／内壁的正面朝向，本轮倒角和田垄也使用顺时针正面；不关闭剔除掩盖错误。暖土色、合并双叶植株和目标脚下薄软影已接入。共同光向微调到(-0.6,0.75,0.3)，山影由同一最高高度场建图生成128×112遮罩；不逐帧追光。低空输入参考面保留，地面对应标记、地块轮廓与低空风线避开新装饰高度。

两尺寸最终各83项地面GPU检查，原云光照／轮廓、雨线／雨区和完整31条路线覆盖通过。完整复跑之后的小配置关系防护及重复高度查询移除另跑相关检查，具体顺序和首轮失败保留在实施记录。热带真实鼠标两种顺序和纯湿开发变体均满风纹；技术证据不等于玩家认可。
