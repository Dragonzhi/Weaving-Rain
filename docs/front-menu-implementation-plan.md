# B「风过群岛」入口界面实施计划

日期：2026-10-15。状态：用户已授权并完成原生接入；以下为实施范围，实际检查与待试玩边界见文末。

## 1. 本轮交付

将[B 交互稿](../design-demos/menu-b.html)落地为 Godot 原生界面：主界面、九宫格选关、玩法说明、声音设置，以及游戏中返回这些页面的完整流转。布局以 B 整体为准，保留奶油底、居中标题、岛屿窗口、横向入口、深青细字和克制风线，不混用 A 的左侧竖排菜单。

复用现有九关、教学、campaign 关序、最高风纹和声音偏好。不改变天气、地块、时限、工具权限、评价或教学内容；不新增锁关、关卡消耗、跨启动天气存档、BGM、正式署名页或地图美术。本轮默认直接在现有 Godot 中试玩，不导出新包。

## 2. 页面和玩家流程

### 主界面

- 上方居中显示《风织雨》及小号英文名；中央岛屿窗口缓慢呈现风线与程序云；下方横向排列「开始旅程／选择关卡／玩法说明／设置」，退出作为次要入口。
- 「开始旅程」复用现有入口偏好：未进入过正式挑战则进入已制作的水库教学；已有偏好则进入 campaign 首关。不会因为曾跳到第九关就自动续到第九关，也不推断新的解锁或推荐算法。
- 本次运行已有未结束的局面时，主要按钮改为「继续本局」，返回相同天气、工具与剩余时间；新开局由选关或重试看见明确入口。只有内存内继续，不承诺关闭程序后恢复天气。
- 教学仍可跳过，完成后进入 campaign 首项；从游戏内重看教学后返回原地图，沿用现有重新开局行为，不将它说成恢复原天气。选关另提供「重看入门」。
- 原生退出按钮正常退出；主界面按 Escape 不直接退出。

### 选关

- 九张地图以三列网格显示缩略图、关号、名称及最高三枚风纹。未取得纪录显示空心风纹，不把没有纪录说成已失败，不显示五角星。
- 单击选择，不直接开始；右侧展示较大地图图像、现有 hint、目标种类与数量、开放工具及明确的「开始本关」。不新增难度星、预计时间或未验证的策略承诺。
- 关号严格取 campaign 数组顺序，文案和工具读地图资源，最高纪录仍以地图 ID 查询。未来多于九关时网格可滚动，详情和开始按钮保持可见，不把九关写死。
- 主界面打开选关，返回主界面；游戏中打开选关，返回当前游戏并恢复进入前的暂停状态。仅选中卡片不重置本局，点击开始并成功加载新地图才切换。
- 打开选关继续事务重读 campaign，坏配置保留上次有效列表；新地图加载失败不销毁当前局面，显示具体问题。无有效列表时显示可理解的错误与重试入口，不回退成开发测试关。

### 玩法说明与设置

- 说明采用三个简短分页：「上山成云与降雨」「田地与蓄水区」「拨风、风带与漩涡」。图标配少量文字，不将它变成强制教程，不强迫玩家先读后玩。
- 准确说明：田地适量后仍需安全，蓄水区蓄满即可；风带和漩涡滚轮三档；漩涡左顺右逆、拖动定半径；工具按关提供。
- 设置只接现有音效开关、总音量，继续使用 WeatherAudio 和 `user://audio.cfg`。主界面与游戏内设置显示同一份值，原有写入合并、失焦静音、渐起退声保留；不添加当前没有的 BGM 滑杆。
- 游戏内说明和设置打开时暂停并取消手势，返回恢复原暂停状态；菜单点击复用已有短音，不播放展示场景的雨声或虚构天气声。

### 暂停与结果

- 游戏内保留紧凑「菜单」入口，将菜单组织为继续、重试、选关、说明、设置、重看入门、返回主界面；开发地图入口仅在原开发条件下可见。
- Escape 在游玩时打开暂停菜单，在子页面返回来源页；空格原有暂停能力保留，菜单里不通过空格误恢复天气。返回按钮与 Escape 遵循同一规则。
- 返回主界面保留本局且暂停；天气、计时、安全确认、风源寿命、三星倒数和天气动画冻结。离开页面后不补算菜单停留时间，不提交残留鼠标手势。
- 原有结果水量、逐目标原因、最高纪录和风纹动画保留，仅统一操作按钮样式并增加返回主界面。成功按 campaign 下一项，最后一关回选关；失败可重试或选关。已结束的本局不显示「继续本局」。

## 3. 原生界面与代码边界

保留 `scenes/main.tscn` 作为运行和测试入口，由 `scripts/main.gd` 协调页面、暂停、地图切换和现有模型。新增 `scenes/front_menu.tscn` / `scripts/front_menu.gd` 承载主界面、正式选关、说明和设置；采用 Godot 原生 Button、Container、ScrollContainer、TextureRect、HSlider 与 Theme，不嵌入 HTML，不手写按钮点击命中。

页面只发出导航、开始关卡、调整音量等意图，不直接修改天气数组、成绩或存档。`game_hud.gd` 继续负责局内目标和工具、结果；将正式选关及设置的入口接到新页面，清理被替代的正式 ItemList，避免同时维护两套正式选关。开发地图浏览保留原独立功能。

使用少量明确页面状态和返回来源，不引入通用路由框架。主界面第一次显示前即阻止正式模拟推进；保留当前初始化方式也必须保证后台没有先跑掉若干步。菜单显示时统一禁止 wind_input，取消续吹、预览及待提交手势；所有每帧重新启用输入的分支同时纳入页面条件，不能只设置一次 enabled。

新增共享菜单 Theme，复用现有深青／奶油／水蓝与风纹绘制。按钮、字体、间距在 Theme 和可编辑场景中集中调整；本轮不再新建一套通用配置加载框架。标题优先实现 B 的轻盈宋体感，保留中文字体回退；正文以可读性为先，不直接沿用 HTML 的小字号。

## 4. 岛屿窗口和缩略图

主界面只使用一个独立展示窗口，复用现有地形、田池和程序云显示，设为不能拨风、不推进教学／结算的展示场景。展示数据与玩家 sim 分离，不写纪录、不改玩家水分；不能为了主界面云形修改正式开局。云保留实时程序渲染，白色风线缓慢移动，地面保持当前纯色风格。

展示窗口从约 960×540 的渲染尺寸起测，按实际窗口限制上限；进入选关、说明、设置或游戏后停止更新。保留中的游戏视口不与它同时绘制；动画使用独立显示时钟，不能推进正式天气或调用成果音效。

选关图使用一次性生成的实际地图开局缩略图，按地图 ID 存于 `assets/ui/level_previews/`，卡片与右侧详情共用同一纹理，不运行九个模拟或九个 SubViewport。增加开发生成工具，读取 campaign 顺序，串行渲染、无玩家输入、不落盘玩家偏好／纪录。地图新增或调整后可重跑工具；没有图时显示名称及中性占位，不妨碍选关。错误时保留旧图，生成过程不能覆盖地图资源。

缩略图只是菜单展示，不作为游戏内云材质；地图布局、文案、目标与工具仍读资源，不能靠图片里的内容决定玩法。

## 5. 尺寸、动效与输入

重点检查实际输出 1920×1080、1280×720、1280×800 及项目当前最小窗口 1100×700。保留原窗口／canvas_items 缩放配置，用容器和锚点适配；较窄尺寸先压缩留白与缩略图，再让网格滚动，不裁掉开始／返回按钮或挤掉长中文标题。

鼠标优先；原生焦点支持 Tab、Enter 和 Escape。切页约 0.15–0.25 秒淡入及短距离位移，按钮即时可用，不能等动画播完才能点击。悬停用细边／轻抬亮，风纹和天气符号复用现有形状，不添加大面积发光、浮动大卡片或频繁弹跳。

整页菜单阻挡天气操作；回到游戏后只实际菜单、按钮和工具栏拦截，不能让隐藏页面继续占据 `blocks_wind()`。测试按钮跨帧按住松开、滑杆拖动、快速连续切页、失焦与视口外松手，防止释放时向场景放出风带或漩涡。

## 6. 开发入口和存档兼容

正常启动改为主界面；`--map`、`--layout`、`--free-play`、`--single-plot`、云／冷风开发小样和编辑器试玩继续直达原场景。为既有独立测试提供明确的跳过前台菜单入口（命令行 `--skip-menu` 或测试实例的启动属性），不要把 `--fresh-guide` 偷换成跳过菜单：它仍只负责忽略／不写玩家资料。

`configs/campaign.tres` 继续是正式关序唯一来源；打开正式选关保留重读及失败回退，R／F6不改变关序。`level_progress.gd` 和版本 2 的风纹纪录不迁移、不重置；教程入口偏好和音效偏好各沿用原文件，不保存虚假的最近天气。

## 7. 实施顺序

1. **入口与返回闭环**：先接原生页面和来源状态，跑通首次教学、已玩入口、暂停、保留本局、选关加载失败和结果返回；此时不追求装饰动效。
2. **选关信息与图像**：九宫格、真实资源详情、最高风纹、缩略图生成工具及缺图回退，保持关序可编辑。
3. **B 方向视觉落地**：统一 Theme、标题与居中构图，接单个展示窗口、轻动效，完成说明和声音设置。
4. **核对与交付**：多尺寸真实点击、完整流程回归、展示渲染成本与局内开销检查，挑选少量截图归档，更新使用指南及看板。

## 8. 验证与完成条件

- **原生点击及生命周期**：首次／已有偏好／本次继续；教学完成与跳过；九关标题、图像、目标、工具及最高风纹一致；增删调序不依赖固定九关；重看教学、暂停开关、说明／设置返回来源；快速切页与原生跨帧按钮可用。
- **不会后台游玩**：主界面停留和各菜单打开前后核对天气数组、计时、安全计时、风源寿命、结果、模拟积累；取消输入后恢复必须重新按下，长时间菜单停留不引发追赶爆发。主界面展示动画不能影响上述字段。
- **失败与保存**：坏 campaign、坏地图、缺缩略图、失败保存均有明确回退；选图失败保留当前局面；最高风纹不降低；设置即时生效且重启保留；`--fresh-guide` 和编辑试玩不读取／写入真实玩家资料；失焦静音和暂停退声保留。
- **完整体验**：真实鼠标从主界面进入正常水汽教学，蓄满后进入 level01，完成真实满风纹倒数，再进入下一关；另验损失／到时结果、末关回选关及返回主界面后继续。显示夹具只证明界面，不替代正常通关证据，也不据此宣称九关全部验证。
- **回归**：因涉及启动、结果和完整流转，运行完整 `tests/run_checks.ps1` 并补前台菜单专项；将旧测试明确配置为直接玩法启动，新增测试覆盖正常主界面启动。保留失败日志，分段续跑注明范围，不改阈值掩盖旧 V6。
- **渲染与性能**：四种尺寸审阅按钮、中文、缩略图和展示图；核对离页后展示窗口零更新、局内无隐藏菜单额外模拟／渲染。对新主界面及正常九关开关菜单做相关短测，记录 P95／P99、长帧及正式模拟推进；正式 V1 长测仍待用户空闲安排，不以菜单短测替代原天气压力验收。

交付原生可点击页面、缩略图生成入口、说明文案、多尺寸审阅截图、实际测试记录及看板更新。B 是已选定的视觉方向；最终字体大小、动效与入口阅读仍需实际试玩确认。

## 9. 实施结果

B 方向已使用原生控件接入：主界面、按真实 campaign 排列的九宫格、三页说明和共用声音设置；游戏／结果返回、暂停与继续本局、开发直达及失败回退均已连接。普通地面、九关布局／数值、天气与评价、纪录格式保持。新增960×540独立展示视口，只在主界面更新；教学加九关共十张640×360缩略图已生成，并通过重复覆盖检查。

最终1920×1080、1280×720、1280×800、1100×700各59项原生交互通过；最终相关编排41、结果47、声音53项通过。从主界面开始的真实鼠标教学→首关→实际满风纹倒数→level02通过，不注水或改规则，完整数据见[审阅记录](front-menu-review.json)。完整回归以最终前段、star-scene起续跑及后续相关复验覆盖，不宣称单次连续全通过；早期声音一次计数失败、旧结果测试布局时序失败均保留在记录。V6历史根因不关闭。

1920×1080新入口四份短样本（每项预热1秒、采样约3秒）全部满足P95≤16.7／P99≤20ms：主界面6.266／6.382、选关6.325／7.945、普通首关10.579／11.322、设置6.269／6.465ms。无超过20ms帧；菜单模拟推进为0，离开主界面后展示更新为0，首关推进3.0／3.0068秒、末积累约2.14ms。此为本机新界面短诊断，不替代天气压力V1正式长测，也不代表风暴性能通过。

[主界面截图](visual-language/menu-review/home.png)、[选关截图](visual-language/menu-review/levels.png)为本轮原生运行图片；其余测试图保留缓存。[操作与缩略图指南](front-menu-guide.md)说明调序和重建方式。新界面实际观感仍待试玩；本轮未导出包、未推送远端。
