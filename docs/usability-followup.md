# 试玩可用性修整：全屏、跨栏拖动与教学范围

日期：2026-10-20。用户确认方案后实施；工程可试玩，未重新导出包体。

## 实际变化

- **F11**在主界面、选关、设置、局内、暂停及结果页切换原生无边框全屏，切回恢复进入前的窗口模式、大小与位置。按键重复事件不会来回切换；切换取消当前手势和按住续吹，已有天气保留。本次运行记忆，不新增存档字段。
- **天气手势拥有输入**：从场景按下的一笔拨风、风带或左／右旋涡，在`_input`阶段接收后续移动、滚轮和松手，可穿过底栏。按钮在整笔期间忽略鼠标；仅拖动靠近底栏30px时以0.14秒淡至18%，退出46px缓冲后恢复，远处拖动不改变透明度，松手不触发按钮；手势结束当下立即恢复输入，不等下一帧。菜单、说明、结果、失焦和离开视口仍保留原有拦截／取消规则。
- **底栏收起**：背景和按钮间空白穿透，按钮仍正常响应新点击。底部正中央的原生向下角标隐藏工具及风源行，收起后原位显示向上角标；不显示中文按钮文字，悬浮说明保留。工具栏上移18px为折叠柄留位；当前工具及风源继续工作，展开后仍可按稳定ID关闭。收起状态在本次运行保留，不写玩家偏好。
- **深色按钮**使用Theme的原生Normal／Hover／Pressed状态：悬浮为更亮的灰青色、细米白边；按下更深；内容边距一致，原金色键盘焦点保留。主菜单与结算使用同一PrimaryButton变化。
- **湿空气教学框**聚焦当前连通湿空气团较明显的核心，以峰值55%／绝对0.15门槛选取；参考尺寸限制在140–260×90–160px，随视口适度放大，每0.12秒更新并平滑跟随。四角括号按1.6秒周期±6%缩放；暂停冻结，设置“减少动态”后静止。框表示从哪里开始拖，不限制框外水汽交互。分裂优先保留当前团，相机／投影／尺寸变化立即重算。
- **教学文字**标题／主行动／详情采用参考18／22／16字号，局部标签17；视口缩放系数0.85–1.35，使用原生多行绘制按实际高度自适应提示卡，不截断长句。教学阶段和天气规则不变。

入口：`scripts/main.gd`、`scripts/wind_input.gd`、`scripts/game_hud.gd`、`themes/front_menu.tres`。设置页添加F11提示，操作说明同步至`docs/demo-delivery/PLAYER_GUIDE.md`。测试入口`tests/test_usability_followup.gd`已接入`tests/run_checks.ps1`。

## 失败与修正

1. 初次导入提示动态视图属性使`camera_changed`不能推断类型，改为显式bool。不能只依据编辑器导入退出0判断无脚本错误，后续原生运行stderr均已检查。
2. 首次专项测试手动关闭前端节点而没有恢复HUD，教学框夹具为空；改用真实`close_front_page()`。只停止命令行明确匹配本次测试的自有进程。截图须等待页面Tween结束，换视图后先初始化显示字段再冻结，避免把中间帧当作画面问题。
3. 旧风工具回归发现松手后的按钮过滤器等下一次绘制才恢复，导致紧接着点击不能选择工具。增加同步恢复，旧36项及新增“松手当下恢复”断言通过。旧测试中“进入底栏就取消”的要求已按新约定改为进入菜单按钮取消，保留强UI边界的检查。
4. 审图发现收起入口与操作说明重叠，移到工具栏右侧；最终两尺寸重新审阅。

下一步由用户试玩近栏才淡化、居中折叠柄和教学聚焦呼吸／文字可读性；现有Demo0.1.1 ZIP仍是本轮改动前版本，待用户要求时统一导出。不新增包、不提交／推送或平台上传。P1／V1／V6及原有外部试玩、声明和日志发布待项保留。
