# 风织雨任务看板

更新：2026-10-13。依据当前可试玩代码、最新用户反馈及策划第36–38节整理。

这里看**现在还有什么没做**；详细规则与讨论历史看[策划记录](cloud-weather-game-design-v0.1.md)。历史章节中曾写“待定／未实现”的内容可能已被后续阶段完成，不直接作为当前待办。

“已实现”表示代码与相应技术检查完成；试玩认可单独记录。“待讨论”表示提过方向但细节尚未定，不代表已排入下一轮开发。用户已完成不同需水地块小样试玩，反馈没有问题，原 D3／V5 已关闭；[实施计划](plot-needs-implementation-plan.md)保留本轮范围与验收方式。

漩涡按用户反馈改为拖动半径、左顺右逆、滚轮三档，水汽覆盖改为圆形核重建。原两圈方案与路线保留为历史；当前技术与试玩边界见[本轮记录](vortex-placement-review.json)。

## 维护方式

每次新增决定、完成实现或收到试玩反馈时，更新对应行及日期。条目从“待讨论”进入开发需要明确方案；代码和测试通过后仍保留未确认的体验问题。策划文档保存决定及理由，本看板只维护当前摘要，README 保留查看入口。
